Toca cualquier estadística para ver una explicación fácil de entender.
% PORCENTAJE
De cada 100 votos registrados, cuántos recibió este candidato. Ejemplo: 35% = 35 de cada 100 personas lo eligieron. Es el indicador más directo de preferencia.
μ PROMEDIO
Si los votos se repartieran igual entre todos, cada candidato tendría este número. Sirve para saber si alguien está arriba o abajo del promedio esperado.
σ DISPERSIÓN
Número alto = un candidato domina claramente. Número bajo = los votos están muy repartidos entre todos. Mide qué tan concentrado está el voto.
± MARGEN ERROR
El resultado real podría variar hacia arriba o abajo por este porcentaje. Con más participantes, el margen baja y el resultado es más confiable.
n TOTAL VOTOS
Cuántas personas han participado en la encuesta. Entre más votos haya, los porcentajes son más representativos de la opinión ciudadana de Silao.
▲▼ TENDENCIA
▲ SUBE = el candidato está ganando preferencia. ▼ BAJA = está perdiendo. — ESTABLE = sin cambios significativos recientes.
